# Google OAuth Troubleshooting Guide

If you are encountering a **403: redirect_uri_mismatch** error when trying to log in with Google, it means the Redirect URI sent by your application does not match exactly what is configured in the Google Cloud Console.

## Quick Fix

1. Go to the **OAuth Debug Page**: [`/oauth-debug`](http://localhost:5173/oauth-debug)
2. Look at the **Generated Auth Parameters** table.
3. Find the value for `redirect_uri`.
4. Copy this value EXACTLY.
5. Go to [Google Cloud Console > Credentials](https://console.cloud.google.com/apis/credentials).
6. Edit your OAuth 2.0 Client ID.
7. Paste the URI into the **Authorized redirect URIs** section.
8. Save and wait 5 minutes.

## Common Issues

### 1. Trailing Slash Mismatch
*   **App sends:** `http://localhost:5173/auth/google/callback/`
*   **Console has:** `http://localhost:5173/auth/google/callback`
*   **Result:** 403 Error. The URIs must match character-for-character.

### 2. Protocol Mismatch (http vs https)
*   **App sends:** `http://localhost:5173/...`
*   **Console has:** `https://localhost:5173/...`
*   **Result:** 403 Error. Localhost is usually `http`, production is `https`.

### 3. Port Mismatch
*   **App sends:** `http://localhost:5173/...`
*   **Console has:** `http://localhost:3000/...`
*   **Result:** 403 Error. Ensure Vite is running on the port you expect.

## Debugging Tools

### Browser Console Logs
Open your browser's developer console (F12) and filter for "OAuth". You will see detailed logs generated by `src/services/googleOAuthService.js` showing:
*   The exact Authorization URL
*   All parameters sent to Google
*   Configuration status
